# Ceazar Jay Diaz — Portfolio

A static portfolio for full-stack, AWS, and conversational AI projects.

## Projects

- Enterprise Contact Center Workflow
- Voice-Activated Process Automation
- Medical Appointment Assistant

Each project uses a custom cover illustration. Selecting a project opens the original implementation screenshot with its technical context.

## Structure

```text
index.html
css/style.css
js/script.js
images/projects/
images/fulls/
```

## Run locally

Open `index.html` directly or serve the directory with any static file server.

```sh
python -m http.server 8000
```
