## 🚀 Getting Started

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/ceazarjaydiaz/ceazarjaydiaz.github.io.git
   ```

2. Navigate to the project directory:
   ```bash
   cd ceazarjaydiaz.github.io
   ```

3. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   ```

### Deployment
The portfolio is automatically deployed via GitHub Pages when changes are pushed to the main branch.
